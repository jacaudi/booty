# Vendored skills

The skill directories here are copied unmodified from
[obra/superpowers](https://github.com/obra/superpowers) at commit
`bb92a77741419a4ab5f06e711a283343f1ada0c3`, under the MIT licence in
`SUPERPOWERS-LICENSE` (Copyright (c) 2025 Jesse Vincent).

To update, copy `skills/*` from a newer superpowers commit over these
directories and change the commit hash above.

`use-modern-go/` is copied unmodified from
[JetBrains/go-modern-guidelines](https://github.com/JetBrains/go-modern-guidelines)
(`plugin/skills/use-modern-go`) at commit `155dc7ca10da5e1f6c841503086957b1b37f5815`
(CLI version `v0.1.1`), under the Apache License 2.0 in `use-modern-go/LICENSE`.
Its wrapper installs the CLI with `go install` into `~/.cache/go-modern-guidelines/`
on first use.
